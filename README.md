# منصة الأستاذ حسين عباس للكيمياء

واجهة تعليمية عربية RTL مع Cloudflare Pages Functions وD1.

## محتويات المشروع
- `index.html` و`app.js`: واجهة عامة، دخول الطلاب، لوحة الطالب ولوحة المدير.
- `functions/api`: واجهات التسجيل والدخول والاختبارات والتقارير.
- `functions/_lib`: كلمات المرور والجلسات.
- `schema.sql`: مخطط قاعدة بيانات D1.

## النشر على Cloudflare Pages
1. من Cloudflare Dashboard افتح **Workers & Pages → Create → Pages → Connect to Git**.
2. اختر مستودع GitHub `dlta30/-` والفرع `main`.
3. اترك Build command فارغاً، واجعل Build output directory هو `.`، ثم Deploy.
4. من إعدادات مشروع Pages افتح **Settings → Functions → D1 database bindings** وأضف binding باسم `DB` واربطه بقاعدة بيانات D1.
5. أنشئ قاعدة D1 باسم مثل `hussein-chemistry`، ثم افتح Console ونفّذ محتوى ملف `schema.sql` كاملاً.
6. من **Settings → Variables and Secrets** أضف Secret باسم `ADMIN_SETUP_KEY` بقيمة عشوائية طويلة لا تقل عن 32 حرفاً. لا تضعه في GitHub ولا تشاركه مع الطلاب.
7. أعد نشر المشروع بعد إضافة الـ binding والـ secret.

## إنشاء حساب المدير لأول مرة
حساب المدير محصور بالبريد المعتمد `auvb2010@outlook.com`. بعد النشر وضبط D1 وADMIN_SETUP_KEY، نفّذ الطلب التالي من جهازك (استبدل القيم محلياً، ولا ترسلها في المحادثة):

```bash
curl -X POST "https://YOUR-PROJECT.pages.dev/api/admin/bootstrap" \
  -H "content-type: application/json" \
  -d '{"setupKey":"YOUR_ADMIN_SETUP_KEY","password":"CHOOSE_A_LONG_UNIQUE_PASSWORD"}'
```

هذا المسار يعمل مرة واحدة فقط، ويرفض إنشاء مدير إضافي بعد وجود حساب مدير. بعد نجاحه سجّل الدخول من الموقع بالبريد المعتمد وكلمة المرور التي اخترتها.

## تنبيه قبل فتح التسجيل للطلاب
- لا تنشر رابط الموقع للطلاب قبل تنفيذ مخطط D1، وربط binding باسم `DB`، وإنشاء حساب المدير وتجربة التسجيل والاختبارات.
- الطلاب يسجلون بأنفسهم، ولا يمكنهم اختيار دور المدير.
- لا يوجد حتى الآن تحقق بريد إلكتروني أو استعادة كلمة مرور أو تحديد محاولات الدخول؛ أضف هذه المتطلبات قبل استخدام المنصة على نطاق واسع.
- خذ نسخة احتياطية دورية من قاعدة D1 وراقب حدود الخطة المجانية.
- الاستضافة المجانية لا تعطي ضمان توفر مطلقاً؛ وقد تنطبق حدود الاستخدام أو صيانة الخدمة.
