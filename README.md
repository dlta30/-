# منصة الأستاذ حسين عباس للكيمياء

واجهة تعليمية عربية RTL مع Cloudflare Pages Functions وD1.

## محتويات المشروع
- `index.html` و`app.js`: واجهة عامة، دخول الطلاب، لوحة الطالب ولوحة المدير.
- `functions/api`: واجهات التسجيل والدخول والاختبارات والتقارير.
- `functions/_lib`: كلمات المرور والجلسات.
- `schema.sql` و`migrations/0001_initial.sql`: مخطط قاعدة بيانات D1 الأساسي.
- `migrations/0003_exam_targets.sql`: جدول تخصيص الاختبارات لكل الطلاب أو شعبة أو طلاب محددين. تنشئ واجهات الاختبارات الجدول تلقائياً عند الحاجة، ويمكن تنفيذ ملف الهجرة يدوياً مسبقاً.

## النشر على Cloudflare Pages
1. من Cloudflare Dashboard افتح **Workers & Pages → Create → Pages → Connect to Git**.
2. اختر مستودع GitHub `dlta30/-` والفرع `main`.
3. اترك Build command فارغاً، واجعل Build output directory هو `.`، ثم Deploy.
4. من إعدادات مشروع Pages افتح **Settings → Functions → D1 database bindings** وأضف binding باسم `DB` واربطه بقاعدة بيانات D1.
5. أنشئ قاعدة D1 باسم مثل `hussein-chemistry`، ثم افتح Console ونفّذ محتوى `migrations/0001_initial.sql` كاملاً (أو `schema.sql`؛ الملفان متطابقان حالياً). نفّذ المخطط مرة واحدة فقط على قاعدة جديدة، وإذا كانت القاعدة تحتوي بيانات فلا تحذفها أو تعِد إنشاءها؛ افحص الجداول أولاً.
6. من **Settings → Variables and Secrets** أضف Secret باسم `ADMIN_SETUP_KEY` بقيمة عشوائية طويلة لا تقل عن 32 حرفاً. لا تضعه في GitHub ولا تشاركه مع الطلاب.
7. أعد نشر المشروع بعد إضافة الـ binding والـ secret.

## إنشاء حساب المدير لأول مرة
حساب المدير محصور بالبريد المعتمد `auvb2010@outlook.com`، ويمكن تسجيل الدخول من واجهة الموقع باسم الأستاذ حسين العباس أو بالبريد. بعد النشر وضبط D1 وADMIN_SETUP_KEY، افتح `/admin-setup.html` لإعداد الحساب، أو نفّذ الطلب التالي من جهازك (استبدل القيم محلياً، ولا ترسلها في المحادثة):

```bash
curl -X POST "https://YOUR-PROJECT.pages.dev/api/admin/bootstrap" \
  -H "content-type: application/json" \
  -d '{"setupKey":"YOUR_ADMIN_SETUP_KEY","password":"CHOOSE_A_LONG_UNIQUE_PASSWORD"}'
```

هذا المسار ينشئ حساب المدير أو يصلح كلمة مروره للحساب المعتمد فقط، ويلغي جلساته القديمة. بعد نجاحه سجّل الدخول من الموقع باسم الأستاذ حسين العباس أو بالبريد المعتمد وكلمة المرور التي اخترتها.

## تنبيه قبل فتح التسجيل للطلاب
- لا تنشر رابط الموقع للطلاب قبل تنفيذ مخطط D1، وربط binding باسم `DB`، وإنشاء حساب المدير وتجربة التسجيل والاختبارات.
- الطلاب يسجلون بأنفسهم، ولا يمكنهم اختيار دور المدير.
- لا يوجد حتى الآن تحقق بريد إلكتروني أو استعادة كلمة مرور أو تحديد محاولات الدخول؛ أضف هذه المتطلبات قبل استخدام المنصة على نطاق واسع.
- خذ نسخة احتياطية دورية من قاعدة D1 وراقب حدود الخطة المجانية.
- الاستضافة المجانية لا تعطي ضمان توفر مطلقاً؛ وقد تنطبق حدود الاستخدام أو صيانة الخدمة.


## تحديث التحقق من تسجيل الطلاب
تم إصلاح تعبيرات التحقق من البريد الإلكتروني وتنظيف الاسم في `functions/api/auth/register.js`؛ يجب أن يتضمن نشر Pages هذا التحديث قبل اختبار تسجيل الطلاب.

## مقاطع الطلاب (رفع فيديوهات مباشرة)
- أُضيف قسم **مقاطع طلاب** للطالب والأستاذ. الطالب يرى مقاطعه فقط افتراضياً، ولا توجد له واجهة أو API لحذفها.
- الأستاذ يرى كل المقاطع ويمكنه إظهار كل مقطع أو إخفاءه، كما يمكنه تفعيل/إيقاف مشاهدة الطلاب لمقاطع الآخرين المنشورة.
- حد الرفع في الواجهة والخادم: 5 دقائق و100 ميجابايت، والصيغ المدعومة MP4 وWebM وMOV. يتحقق المتصفح من مدة الفيديو قبل الإرسال.
- ملفات الفيديو تحفظ في Cloudflare R2، أما بياناتها وصلاحياتها فتحفظ في D1.

### إعداد التخزين قبل تجربة القسم
1. من Cloudflare افتح **R2 Object Storage** وأنشئ bucket باسم مثل `hussein-student-videos`.
2. افتح مشروع Pages ثم **Settings → Functions → R2 bucket bindings**.
3. أضف binding بالاسم الدقيق `STUDENT_VIDEOS` واربطه بالـ bucket الذي أنشأته.
4. افتح D1 Console لقاعدة بيانات المنصة ونفّذ محتوى `migrations/2026-11-student-videos.sql` مرة واحدة.
5. أعد نشر Pages، ثم سجّل الدخول بحساب طالب وارفع مقطعاً تجريبياً. ادخل بحساب الأستاذ لمراجعته وإظهاره.

**مهم:** لا ترفع ملفات الفيديو إلى GitHub أو D1؛ مكانها R2. روابط تشغيل الفيديو تمر عبر واجهة محمية تتطلب جلسة دخول، ولا يستطيع الطالب حذف مقطعه.
